# Flying Bird 🐤🎮

> Game arcade berbasis web yang terinspirasi dari Flappy Bird dengan gaya visual yang bersih, simpel, dan responsif!

---

## 📸 Tampilan Game

Game **Flying Bird** menampilkan desain bertema langit biru yang cerah lengkap dengan elemen awan, latar belakang perkotaan, serta burung animasi yang siap terbang melewati rintangan.

---

## ✨ Fitur Utama

* **Kontrol Mudah & Responsif:** Mainkan menggunakan tombol **Spasi** pada keyboard atau dengan **Mengetuk Layar (Tap/Click)**.
* **Tampilan Ringan & Bersih:** Tanpa perlu instalasi tambahan, langsung dapat dimainkan melalui browser web.
* **Single File Project:** Seluruh logika game, struktur HTML, styling CSS, dan aset telah terintegrasi dengan rapi dalam satu file `index.html`.

---

## 🎮 Cara Bermain

1. **Memulai Game:** Buka file `index.html` di browser favorit Anda.
2. **Terbang:** Ketuk layar atau tekan tombol **Spasi** untuk membuat burung melompat/terbang ke atas.
3. **Hindari Rintangan:** Jaga agar burung tidak menabrak rintangan atau jatuh ke tanah.
4. **Skor:** Raih skor tertinggi dengan bertahan hidup sepanjang mungkin!
